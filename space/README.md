# GenBrick — BrickNet caption-to-design generation

Fan project, not affiliated with or endorsed by the LEGO Group.

Type a caption describing a build idea and get back a novel LEGO design,
generated by [BrickNet](https://github.com/kulits/BrickNet) (a
`Qwen/Qwen3-0.6B` LLM with two stacked LoRA adapters) as raw LDR text.

This Space is the backend for [GenBrick](https://github.com/Agent-XC/GenBrick)'s
Phase 2 caption-to-design feature — see `PHASE2_PROJECT_SPEC.md` and issue #18
in that repo for the full design.
